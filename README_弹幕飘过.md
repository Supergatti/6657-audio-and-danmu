# 🎉 斗鱼弹幕飘过服务器使用说明

## 功能特点

✨ **实时弹幕飘过效果** - 弹幕从右向左平滑飘过，完美还原弹幕体验
🎮 **交互控制** - 可调节速度、字体大小、透明度等
📊 **实时统计** - 显示弹幕数量、连接状态等信息
💾 **智能缓存** - 每500条弹幕自动清空，不占用存储空间
🌈 **彩色显示** - 每条弹幕随机颜色，视觉效果更佳

## 安装依赖

```powershell
# 安装必要的Python包
pip install playwright websockets

# 安装Chromium浏览器
playwright install chromium
```

## 使用方法

### 1. 启动弹幕飘过服务器

```powershell
# 基本用法（使用默认房间）
python douyu_danmaku.py

# 指定房间ID
python douyu_danmaku.py --room-url https://www.douyu.com/你的房间号

# 修改端口
python douyu_danmaku.py --port 8888

# 显示浏览器窗口（调试用）
python douyu_danmaku.py --headed

# 调整缓存大小
python douyu_danmaku.py --max-cache 1000
```

### 2. 打开弹幕墙页面

服务器启动后，在浏览器中打开：

```
http://127.0.0.1:8766
```

或者在控制台中会显示完整的访问地址。

### 3. 控制弹幕效果

页面右侧控制面板提供以下功能：

- **速度调节**：5-20秒，控制弹幕飘过速度
- **字体大小**：16-40px，调整弹幕字体大小  
- **不透明度**：50-100%，调整弹幕透明度
- **暂停/继续**：暂停或恢复弹幕显示
- **清空屏幕**：清除当前显示的所有弹幕

## 命令行参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| --room-url | https://www.douyu.com/6979222 | 斗鱼房间URL |
| --room-id | 无 | 房间ID（可选，从URL提取） |
| --host | 127.0.0.1 | 服务器绑定地址 |
| --port | 8766 | 服务器端口 |
| --max-cache | 500 | 最大缓存弹幕数（达到后清空） |
| --debug | False | 启用调试日志 |
| --headed | False | 显示浏览器窗口 |

## 技术特点

- **WebSocket实时通信**：延迟极低，弹幕即时显示
- **自动缓存管理**：每500条自动清空，避免内存占用
- **多轨道显示**：智能分配12个轨道，避免弹幕重叠
- **断线重连**：WebSocket断开后自动重连
- **响应式设计**：支持PC和移动端

## 注意事项

⚠️ **不保存日志**：此版本不会将弹幕保存到文件，仅用于实时展示
⚠️ **缓存限制**：默认500条弹幕后清空缓存，可通过 `--max-cache` 调整
⚠️ **浏览器兼容**：推荐使用Chrome、Edge、Firefox等现代浏览器

## 常见问题

**Q: 无法连接到服务器？**
A: 确保防火墙允许8766端口，或更换其他端口

**Q: 弹幕不显示？**
A: 检查控制台是否有错误，确认房间正在直播

**Q: 如何修改弹幕颜色？**
A: 编辑 `web/danmaku_wall.html` 中的 `colors` 数组

**Q: 想要保存弹幕怎么办？**
A: 使用 `douyu_service.py` 而不是 `douyu_danmaku.py`

## 停止服务

在运行的终端中按 `Ctrl+C` 即可停止服务器。
